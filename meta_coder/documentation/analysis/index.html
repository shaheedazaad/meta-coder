METACODER / USER GUIDE

Define your analysis¶

The effect definition tells the model which comparison to code. Write it before you create fields or run extraction; a blank definition leaves the manual incomplete.

Describe the comparison¶

  1. Open Define your analysis in the project sidebar.
  2. Enter the analysis name and an optional description.
  3. Write an Effect definition that identifies the outcome and comparison.
  4. Choose Validate and save.

For example: “The difference in response time between incongruent and congruent trials, separately for each experiment.” This gives the coding fields a common reference point. Use each coding-sheet row's locator to distinguish experiments, outcomes, or conditions within a paper.

Save before moving on¶

The analysis definition and coding fields are part of the same saved manual. Save edits before running extraction. Saving a changed manual clears existing extraction results, so export results first if you need to preserve an earlier run.
