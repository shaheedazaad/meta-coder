# PDF matching

PDF matching connects coding-sheet rows to uploaded studies. Review suggested matches before accepting them, especially when authors or publication years overlap.

[![PDF matching with the needs PDF, suggestions, matches, and orphan sections](assets/screenshots/matching.png)](assets/screenshots/matching.png)

## Review the matching sections

| Section | What to check |
| --- | --- |
| Needs PDF | Sheet entries still missing an uploaded study |
| Suggestions | Candidate matches based on available file and paper information |
| Matches | The saved connections between sheet entries and PDFs |
| Orphans | Uploaded PDFs with no coding-sheet rows |

Background scanning gathers matching information after uploads. Let it finish, review the suggested source for each paper, and save the appropriate matches. Only high-confidence suggestions are preselected. Medium and low suggestions are marked “(suggested)” in the list but stay unselected until you choose them, so **Apply this page** saves only the matches you can see selected. A suggestion is shown as low when the PDF's publication year differs from the sheet's, or when another PDF or paper fits almost as well. Confirm that each locator actually points to the intended effect in that PDF.

## Fix a wrong match

Remove the incorrect saved match, then select the correct uploaded PDF. If the study is missing entirely, add it in [Source PDFs](sources.md) and return here.

## Before running

At least one coding-sheet row must match an uploaded PDF. Unmatched rows and orphan PDFs are skipped when you run extraction. Resolve all intended matches if you want complete coverage of your sheet.
